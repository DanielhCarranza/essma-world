## Usage rule

These files are **reference-only**. They are not runtime assets, source art, a license to reproduce any visible logos or copyrighted material, or a template to copy screen-for-screen. Derive original work from their high-level qualities:

- warm Sonoran golden-hour light, terracotta, marigold, cactus green, cobalt, and desert-pink accents;
- tactile adobe, wood, leather, textile, paper, and ceramic materials;
- child-friendly silhouettes and expressive, consistent characters;
- a clear playable center with layered ranch depth;
- playful, readable Spanish-first controls.

Several references include third-party marks or non-product graphic material (for example, Nintendo/Switch or ESRB imagery). Those elements are explicitly excluded from Essma World production.
